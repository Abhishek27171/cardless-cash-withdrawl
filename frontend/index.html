Emergency Cash Access
Without a Physical Card

Inspired by metro QR ticketing, this system allows students and users in emergencies to withdraw cash using a secure, time-bounded dynamic QR code (60s TTL) with MPIN and OpenCV Face Verification.

1. The ATM Machine Kiosk

Selects amount, generates a dynamic HMAC-signed QR code valid for only 60 seconds (max 3 regenerations), and dispenses cash in real time via WebSockets when approved.

Launch ATM Screen

2. The Mobile Banking App

Scans the ATM QR using the phone camera, prompts for a 4-digit MPIN, and conducts a live facial recognition match using computer vision before authorizing the debit.

Academic Subjects & Concepts Applied

Use this breakdown during college viva, evaluations, and project reports:

Cryptography & Sec (CNS)
  • HMAC-SHA256 signature verification
  • Nonces to prevent Replay Attacks
  • Time-To-Live (60s dynamic expiry)
  • Session rate-limiting (Max 3 attempts)
Networks & Real-Time (CN)
  • Full-duplex WebSockets (/ws/atm)
  • Client-Server REST APIs (FastAPI)
  • Real-time event push to ATM screen
  • Low-latency handshake
Computer Vision & AI (CV)
  • OpenCV Haar Cascade Face Detection
  • Histogram equalization & preprocessing
  • Normalized cross-correlation comparison
  • Toggleable 2FA Biometric authentication
